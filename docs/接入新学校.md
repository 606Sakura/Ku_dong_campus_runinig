# 接入新学校

本文说明三件事：`baseUrl` 填什么、`signSecret` 从哪来、绑定码怎么拿。
仓库里所有真实地址与学校信息都已替换为占位符，你需要自己填。

---

## 1. 准备

```bash
cp config.example.json config.local.json
```

`config.local.json` 已在 `.gitignore` 里，填什么都只留在本机。

**分发场景**：不想让每个用户手工复制时，把这四个字段填进 `config.seed.json`（同样不入库）。`启动.cmd` 首次运行发现没有 `config.local.json` 就自动复制一次，之后用户改过的值不会被覆盖。

```json
{
  "baseUrl": "",
  "signSecret": "",
  "port": 8787,
  "host": "127.0.0.1",
  "demoPort": 8788,
  "stateFile": "state.json",
  "schoolLat": "",
  "schoolLng": ""
}
```

`schoolLat` / `schoolLng` 是选填的校内坐标：浏览器定位被拒或不可用时，页面用它去取附近路线。在地图上取操场中心的经纬度，精确到小数点后 6 位即可。

**也可以让工具自己检测这两项**：

```bash
node tools/auto-config.js --dry     # 只报告，不写
node tools/auto-config.js           # 写进 config.local.json
```

`get-bind-code.cmd` 会先跑它。检测范围是 `%APPDATA%\Tencent\xwechat\radium\users\<uid>\applet\packages\` 下所有 `__APP__.wxapkg`（旧版微信的 `%APPDATA%\Tencent\WeChat\...` 也看）。命中的判据是包里出现接口路径与 `sunshine-run` 头；`baseUrl` 由主机加代码里的路径前缀拼出，`signSecret` 取全包唯一的 64 位十六进制常量——出现多个就报错不猜。解包只在内存里做，不落盘。

## 2. `baseUrl`：平台接口根地址

校园跑平台通常以「学校标识 + 域名」区分。你需要找到**你所在学校**的接口根地址。

**方法 A：从绑定码的响应里读（推荐）**

绑定成功后，平台返回的用户档案里有 `serverUrl` 字段，它就是根地址：

```bash
node -e "const st=require('./state.json');for(const k of Object.keys(st.accounts)){console.log(st.accounts[k].user.serverUrl)}"
```

把它原样填进 `baseUrl`（不要漏掉路径前缀，例如 `/xxx`）。

**方法 B：从微信小程序里找**

1. Windows 版微信打开小程序，登录你的账号；
2. 用抓包工具（mitmproxy / Charles）看小程序发出的请求；
3. 找带 `serverUrl` 或形如 `https://<主机>/<前缀>/users/profile` 的地址；
4. 取到 `<前缀>` 为止的部分。

> 注意：不同学校的域名与前缀可能不同。不要照抄别人的地址，也不要写死在小程序之外的公共值。

## 3. `signSecret`：请求签名密钥

提交跑步的三个接口（`POST /runs`、`POST /runs/sessions/start`、`POST /runs/sessions/:id/finish`）需要 HMAC-SHA256 签名。

签名基串为 8 段，`\n` 连接，末尾再补一个 `\n`：

```
v1
{METHOD}
{path}
{unix 秒时间戳}
{16 字节随机 nonce 的 hex}
{sha256(token)}
{sha256(deviceId)}
{sha256(bodyString)}
```

密钥是**硬编码在小程序客户端里**的（各校通常是同一份）。获取方式：

1. 优先用 `node tools/auto-config.js` 自动检测（见第 1 节）；
2. 手工方式：用 `wxapkg` 解包工具拿到小程序的 `app-service.js`；
3. 搜索 `hmac`、`sha256`、`sign`、`createHmac` 附近的常量；
4. 找到 64 位十六进制字符串，就是 `signSecret`。

拿到后填进 `config.local.json`。**不要把它提交到任何公开仓库**——本项目已内置 `tools/check-secrets.js` 在 `npm test` 中拦截。

## 4. 绑定码

绑定码 = `Base64(UTF8({"t":"<token>","d":"<deviceId>","f":"<fp>"}))`，无加密无加盐。

### Windows（完整流程）

1. 登录 Windows 版微信，打开校园跑小程序并停在**首页**；
2. 双击 `取绑定码并绑定.cmd`；
3. 脚本从微信进程内存读 token，自动 POST 到本机服务完成绑定。

只想要码、不想自动绑定：

```bash
node tools/取绑定码.js          # 打印 Base64
node tools/取绑定码.js --mask   # 只打印字段长度，适合排查
```

### macOS / Linux

取码依赖读取 Windows 版微信进程内存，这两个系统上跑不了。两条退路：

- 借一台 Windows 电脑运行 `node tools/取绑定码.js`，把输出的 Base64 串带回本机，粘贴到网页绑定框；
- 或在 Windows 上完成绑定后，把 `state.json` 拷到本机。

### 手动粘贴

网页绑定框只接受那段 Base64 字符串，直接粘贴即可。

## 5. 多校登记（可选）

如果你要帮多个学校的同学登记：

```bash
cp schools.example.json schools.json
```

逐条填写：

```json
{
  "schools": [
    { "name": "甲校", "code": "<甲的 base64 绑定码>" },
    { "name": "乙校", "code": "<乙的 base64 绑定码>" }
  ]
}
```

校验：

```bash
node tools/校验多校.js          # 只解码检查 t/d/f 字段
node tools/校验多校.js --probe  # 额外把每条 code 绑到临时 state 副本上实测
```

`--probe` 不会碰你的真实账号，会临时起一个假平台与被测服务，跑完自动清理。

**一条都通不过时脚本会以非零退出码结束**，避免空模板被当成通过。

---

## 6. 验证接入成功

启动后终端应显示：

```
校园跑 · 新版本  http://127.0.0.1:8787/
  真实模式，平台 BASE = <你填的地址>
  多校登记表：N 所（已填绑定码 M 所）→ ...   # 只有创建了 schools.json 才有这行
```

页面上：

- 顶部**没有**黄色「演示模式」横幅；
- 右上角徽章显示「直连平台」；
- 绑定后能看到姓名、学号、学校名；
- 「获取附近路线」能返回你学校的路线与打卡点。

任何一步不对，先看 README 的故障排查，再运行 `npm test` 排除代码问题。
